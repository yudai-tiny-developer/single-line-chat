# Improve YouTube Live Chat

A Chrome extension that makes YouTube live chat easier to scan by turning messages into a cleaner single-line layout and letting you hide or restyle chat elements.

## Features

- Convert regular live chat messages into a compact single-line layout
- Hide author photos
- Hide author names
- Hide chat badges
- Hide chat XP buttons
- Change message text colors
- Change message background colors

## Usage

1. Open a YouTube live chat or live chat replay.
2. Click the extension icon.
3. Toggle the settings you want.

The popup is also used as the extension's options page.
